# Agent Note: 外部运行时只在设置页显式选择后安装

Status: implemented

## 问题

外部程序缺失会阻止用户启用编辑器。要求用户离开插件设置手工部署，无法提供与 DSH 内置语音输入一致的准备进度和失败恢复入口。

## 决策

本决策替代[解耦决策](2026-10-25-dsh-decoupling.md)中禁止插件提供外部程序安装能力的部分；公开扩展点、独立分发与不隐式下载的约束继续适用。插件默认配置不下载、不安装；设置页显示来源和目录，用户点击安装后才执行，加载插件或保存配置均不触发下载。

版本、来源和安装目录通过插件 `Config` 校验，文件存放在插件拥有的目录，不修改系统 PATH 或安装系统依赖。下载过程支持取消和重试，校验发布者摘要后才启用文件；插件销毁会取消并等待进行中的安装清理。已有外部程序仍可通过路径或服务地址接入，缺失只停用依赖它的功能。具体支持范围和操作归[Editor](../../../../packages/editor/README.md#按需安装)所有。

## 考虑过的替代方案

**完全交由部署环境安装。** 这是解耦决策的安装策略，无法在插件设置中辅助首次使用者完成依赖准备与失败恢复。

**插件加载时自动安装。** 加载与保存配置不表达下载授权，隐式联网与安装会增加部署副作用，且无法让用户先确认来源和目录。

## 后果

用户可在设置页完成运行时准备，插件需要承担下载校验、进度、取消和清理。系统依赖与不支持的平台仍由部署环境准备；单次安装选择不授权未来自动下载其他版本。
