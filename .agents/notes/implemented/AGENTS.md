# AGENTS.md：已落地的 Agent Notes

这些 Agent Note 描述已落地的决策。遵守 [根规则](../../../AGENTS.md)、[文档规范](../../../docs/AGENTS.md) 和 [Agent Note 格式](../README.md#文件格式)。

## 让已落地的 Agent Note 与实际落地的内容保持一致

路径、符号、默认值和机制改变时，在同一次改动中更新 Note。直接改写过期的事实，不追加变更历史。

### 这不是改写决策的许可

事实层面的落地细节直接更新。推翻决策或其理由需要写一个新的 Agent Note 并互相链接；被完全取代的旧 Note 只能按 [Agent Note 规则](../README.md#合并与删除) 中的合并规则删除。
