# @amadeus-dsh/test

加载时在终端打印 `[amadeus-test] plugin loaded!` 的最小 DSH 插件，不注册任何能力。它是仓库内的插件示例，也是文档门禁和插件测试的检查对象；`package.json` 声明了 `"private": true`，不发布到 npm。

在本仓库中验证它能被 DSH 加载：在本目录运行 `pnpm pack`，再按根 [AGENTS.md](../../AGENTS.md#命令) 的本地验证方法装进隔离的 `DSH_HOME`。

## 模型体验

无，因为插件只在加载时向终端打印一行日志，不注册工具、提示词或会话记录，不向模型请求添加任何内容。

## 已知限制与延期工作

- **不发布**：npm 上的 `0.0.0-stage`、`0.1.0`、`0.1.1` 只用于验证发布流程，已标记弃用，不再更新。
- **不注册任何能力**：插件只在加载时打印一行日志，没有工具、服务、配置或界面。
